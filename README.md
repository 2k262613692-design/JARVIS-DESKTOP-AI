# ⚡ J.A.R.V.I.S. — Advanced Native Desktop AI Assistant

An offline-capable, high-performance desktop assistant engineered with biometric security, dynamic theme management, dynamic HUD telemetry, and local LLM fallback.

Developed by *Tanishq Tiwari* | PSIT - Computer Science & Engineering

---

## 🌟 Architecture & Features
- 🛡️ *LBPH Biometric Security Gate:* Zero-error facial authorization protocol at startup (THREAT DETECTED // ACCESS DENIED).
- 🔴 *Crimson Red Alert / Alpha Override:* Voice/text triggered emergency theme switching ("Jarvis override alpha").
- 📊 *Dynamic Telemetry Canvas:* Multi-threaded Tkinter graphical interface displaying live CPU, RAM, Disk hardware diagnostics.
- 🎙️ *Thread-Safe Speech Processing:* Asynchronous voice synthesis paired with emergency speech halt capabilities.
- 🧠 *Offline LLM Intelligence:* Integrated with Ollama (llama3.2:1b) for fast offline interaction.
